# Agent Notes — Corrections & Standing Directives

Read this file at the start of every session before doing any work.

This is an append-only running log of user corrections and standing always/never directives.

- Append one line per directive proactively (without being asked) whenever the user makes a correction or gives an always/never instruction.
- Newest lines at the bottom.
- One line per entry.
- When a new directive supersedes an earlier one, update or remove the stale line rather than leaving both.
